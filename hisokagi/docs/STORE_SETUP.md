# 課金と広告の設定手順

コードは組み込み済みです。ここに書いてあるのは、ストアの管理画面と AdMob で人がやる作業です。上から順に進めてください。

## 1. ひそかぎパスの商品を作る

### App Store Connect

1. アプリ「ひそかぎ」（Bundle ID `com.ookura.hisokagi`）を作る
2. 「App内課金」で **非消耗型** を追加する
   - 製品ID：`hisokagi_pass`（コードと完全に一致させる）
   - 参照名：ひそかぎパス
   - 価格：¥600
   - 表示名：ひそかぎパス
   - 説明：広告が出なくなり、ヒント2と答えが広告なしで開きます
3. 審査用のスクリーンショットに、パスの画面（タイトル →「ひそかぎパス・購入の復元」）を使う
4. 最初の審査は、アプリ本体と一緒に App内課金 を提出する

### Google Play Console

1. アプリ「ひそかぎ」（パッケージ名 `com.ookura.hisokagi`）を作る
2. 「収益化 → アプリ内アイテム」で **アイテム** を追加する
   - アイテムID：`hisokagi_pass`
   - 名前・説明・価格は App Store と同じ
3. 内部テストのトラックにアップロードしてから、ライセンステスターで購入を試す

## 2. AdMob の本番IDに切り替える

1. AdMob でアプリ「ひそかぎ」を iOS と Android で1つずつ作る
2. 各アプリに広告ユニットを2つ作る：**リワード**（ヒント用）、**インタースティシャル**（クリア後用）
3. 次の4か所を書き換える

| ファイル | 書き換えるところ |
| --- | --- |
| `lib/monetize/ad_unit_ids.dart` | `_rewardedAndroid` `_rewardedIos` `_interstitialAndroid` `_interstitialIos` を本番IDに。`isPlaceholder` を `false` に |
| `ios/Runner/Info.plist` | `GADApplicationIdentifier` を iOS の本番アプリID（`ca-app-pub-…~…`）に |
| `android/app/src/main/AndroidManifest.xml` | `com.google.android.gms.ads.APPLICATION_ID` を Android の本番アプリIDに |

- `isPlaceholder` が `true` のままリリースビルドを作ると、広告は出ません（ヒントは広告なしで開きます）。テスト広告が本番で出ることはありません
- デバッグビルドでは、常に Google のテスト広告が出ます
- AdMob の「プライバシーとメッセージ」で、EEA・英国向けの同意メッセージ（GDPR）を作成・公開する。アプリは起動時に自動で表示します
- AdMob の「ブロックのコントロール」で、広告の最大コンテンツレーティングを G にする（アプリ側でも G に絞っています）

## 3. プライバシーの表示

広告SDK（Google Mobile Ads）が端末の識別子や広告の利用データを集めます。アプリ自体はサーバーに何も送りませんが、「収集なし」にはできません。

- **App Store のプライバシー**：Google の案内（[AdMob のデータ開示](https://developers.google.com/admob/ios/privacy/data-disclosure)）に沿って回答する。ATT は出さないので、「トラッキングに使用」は付けない
- **Google Play のデータセーフティ**：Google の案内（[Google Mobile Ads SDK のデータ開示](https://developers.google.com/admob/android/privacy/play-data-disclosure)）に沿って回答する
- **プライバシーポリシー**：広告SDKを使っていること、非パーソナライズ広告のみであること、購入情報はストアが扱うことを書き、ストアの掲載情報とアプリ内の両方からリンクする（アプリ内のリンクはまだ置いていない）
- Android の `AD_ID` 権限は広告SDKが自動で追加します。データセーフティでも「広告ID」を申告してください

## 4. 審査メモ（App Store）

次の内容を英語で書いておくと、確認が速くなります。

- 2台で遊ぶゲームだが、タイトルの「1台で遊ぶ（交代しながら）」で、1台で全ステージを確認できる
- シナリオ1の答え（部屋番号ごとに変わるため、ヒント画面の「答えを見る」で確認できる）
- ひそかぎパスは非消耗型。特典は「広告なし」と「ヒント2と答えが広告なしで開く」
- 通信は広告とストアにだけ使う。ゲーム自体は通信なしで遊べる

## 5. 実機で確かめること

- [ ] iOS：Sandbox アカウントで購入 → アプリを消して入れ直し →「購入を復元する」でパスが戻る
- [ ] Android：ライセンステスターで購入 → アプリを消して入れ直し → 起動するだけでパスが戻る
- [ ] 購入の途中でキャンセルしても、パスにならず、エラーも出ない
- [ ] 機内モード：ヒント2が広告なしで開く。パスを持っていれば、購入済みのまま
- [ ] テスト広告：ヒント2でリワード、クリア後にインタースティシャルが出る。プレイ中には出ない
- [ ] EEA の端末（または UMP のテスト設定）：起動時に同意フォームが出る
