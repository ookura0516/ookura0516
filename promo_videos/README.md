# 宣伝動画（ホシムスビ・ネジマキ・ハナビシ・マスメ）

設計書「Web体験つきアプリ4案」の4案それぞれの宣伝動画を作る仕組みです。字幕と図で見せる紹介動画で、声はあとから重ねます。

| 案 | 縦型 9:16 | 横型 16:9 | 公開予定 |
| --- | --- | --- | --- |
| ネジマキ（オルゴール作曲） | 約21秒 | 約43秒 | 2027年3月 |
| マスメ（すごろくメーカー） | 約22秒 | 約46秒 | 2027年4月 |
| ホシムスビ（星座づくり） | 約20秒 | 約39秒 | 2027年6月 |
| ハナビシ（花火づくり） | 約23秒 | 約39秒 | 2027年7月 |

- アプリはまだないので、どの動画にも「画面は開発中のイメージです」と出します。ストアのバッジは入れていません
- 音はすべてこの仕組みで合成しています（録音素材なし）。ネジマキのメロディは著作権の切れた「きらきら星」です
- 花火は画面全体を光らせる演出を使っていません（光過敏への配慮）
- 字体は Noto Sans JP、Zen Maru Gothic、Shippori Mincho（いずれも SIL Open Font License）

## 作り方

必要なもの：Node.js 22、Playwright の Chromium、ffmpeg、Python 3 と numpy・Pillow

```sh
npm install                 # 字体（@fontsource）を入れる
./build.sh                  # 8本すべて → out/<案>_<V|H>_novoice.mp4
./build.sh nejimaki V       # 1本だけ
./preview.sh masume H       # 確認用：場面ごとの静止画の一覧 → out/sheet_masume_H.png
```

## 声を入れる

1. `ナレーション台本.md` の文を1行ずつ音声にして、`voice/<案>_<V|H>/01.wav`、`02.wav` … に置く（aiff・m4a・mp3 も可）
2. `python3 mix_voice.py <案> <V|H>` → `out/<案>_<V|H>_final.mp4`

声は台本の位置から鳴り、背景音は声のあいだだけ小さくなります。声が「長さの上限」を超えると 1.15 倍まで速め、それでも超えると知らせます。声が全体に遅い場合は `CPS=5.5 ./build.sh` で場面を長くして作り直してください。

macOS の読み上げで仮の声を入れるだけなら、次の1行で8本できます（声なし版を `out/` に置いてから実行）。

```sh
python3 mix_voice.py --all --say Kyoko
```

## 名前や台本を変える

名前はすべて仮称です。変えるときは `apps/<案>.js` の `name`・`catch`・`scripts` を直して `./build.sh <案>` を実行します。字幕・終わりの画面・ナレーション台本がまとめて変わります。

| ファイル | 中身 |
| --- | --- |
| `apps/*.js` | 案ごとの台本、色、図、音の合図 |
| `lib.js`・`main.js` | 共通の部品と、台本から時間割を作る処理 |
| `render.mjs` | ブラウザで1コマずつ描いて動画にする |
| `audio.py` | 背景音と効果音の合成 |
| `narration.py` | ナレーション台本と時間割（`timelines/`）を書き出す |
| `mix_voice.py` | 声を重ねて完成版を作る |
