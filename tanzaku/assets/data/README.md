# 歳時記データ

- `kigo.json`：季語。`tool/build_kigo.py` から作る。手で直接直さない
- `yomi.json`：音数の目安に使う、季語以外のよくある語の読み

## 季語を足す（600語まで）

1. `tool/build_kigo.py` の季節の区切りの**末尾**に `k(...)` の行を足す。途中に挿し込むと id がずれ、保存済みの句の季語がずれる
2. `data = {...}` の `"version"` を1つ上げる（アプリが起動時に入れ直す）
3. `python3 tool/build_kigo.py` を実行する
4. `flutter test test/kigo_test.dart` を通す。150語の数を確かめるテストは、増やした数に直す

| 項目 | 書き方 |
| --- | --- |
| 語 | 見出しの表記（例：木枯） |
| 読み | ひらがな（例：こがらし）。音数の目安にも使う |
| 分類 | 時候・天文・地理・生活・行事・動物・植物 |
| 時期 | 新年・初春・仲春・晩春・三春（夏秋冬も同じ）。日付は `PERIODS` の表から決まる |
| 期間の上書き | その日だけの季語（元日、大晦日など）は `span=("12-31", "12-31")` |
| 説明 | 80字以内で自分で書く。歳時記や辞書の文を写さない |
| 別表記 | 旧仮名、かな書き、傍題。2音以下のかなは他の語に紛れるので避ける |
| 例句 | 芭蕉・蕪村・一茶・子規の句だけ。その季語1つだけが見つかる句にする（テストで確かめる） |
