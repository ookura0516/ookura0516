# ひそかぎ 設計書

2〜4人がそれぞれ自分のスマホを持ち寄り、画面に出る「自分だけの手がかり」を声で伝え合って解く協力謎解きです。通信もサーバーも使いません。

- 企画の背景と調査：[謎解きアプリ企画書（収益化・企画検証編）](https://claude.ai/artifact/T6Q1ggwUrTdc1iZTdoRYLm) の企画案①
- 対象：2人組（カップル・親子・友人）。3〜4人版は売れてから追加シナリオとして出す
- 1シナリオ 20〜40分

## 1. 遊びの流れ

1. 親が「部屋をつくる」でシナリオを選ぶと、6桁の**部屋番号**と自分の役が出る
2. 相棒は「部屋にはいる」で同じ番号を入れる。相棒には別の役が割り当てられる
3. 各ステージで、2人の画面にはちがう手がかりが出る。声で伝え合わないと解けない
4. 答えを入れる端末はステージごとに決まっている（交互）。正解すると、その端末に**合言葉**が出る
5. 相棒は合言葉を自分の端末に入れて、次のステージに進む
6. 最後のステージを解くと、2人それぞれの立場からエンディングが読める

1台しかないときは「1台で遊ぶ」を使う。画面の上で役を切り替え、切り替えのたびに目隠し画面を挟む。合言葉は要らない。このモードは、App Reviewの担当者が1台で全部を確認する手段にもなる。

## 2. 通信なしで2台をそろえる仕組み

### 部屋番号（6桁）

| 桁 | 意味 |
| --- | --- |
| 1 | シナリオ番号（0〜9） |
| 2 | 人数（2〜4） |
| 3〜5 | シード（000〜999） |
| 6 | 検査数字 |

- 検査数字は、先頭5桁と**ルール版数**から計算する。アプリのバージョンが違ってシナリオの中身が変わっている場合、番号が通らない（約9割の確率で弾ける）。そのときは「番号がちがうか、アプリのバージョンがちがいます」と出す
- シードから、記号の並び・ケーブルの色・時計の時刻・暗号の単語などを決める。同じシナリオでも部屋番号が違えば答えが変わるので、ネタバレが広まっても困らない
- 乱数は自前の32ビットの決定的な乱数（`lib/core/rng.dart`）を使う。Dart標準の `Random(seed)` は、SDKのバージョンによって結果が変わらない保証がないため使わない

### 合言葉

- ステージを解いた端末だけが、合言葉（ひらがな3〜4文字）を表示する
- 合言葉は「シナリオ・シード・ステージ番号」から決まる。相棒の端末も同じ計算をして、入力と照合する
- 合言葉は答えそのものではない。相棒のステージを先に開いてしまうことを防ぎつつ、答えを声に出すだけで進めてしまうことも防ぐ

## 3. シナリオ1「閉館後の天文台」（無料・2人用）

- 役A **ドームの中**：閉館後のドームに閉じ込められた
- 役B **管制室**：外の管制室で、古い観測ノートを見つけた
- 今夜0時に流星群が来る。それまでにドームの屋根を開けたい

| # | ステージ | Aに見えるもの | Bに見えるもの | 答えを入れる側 | シードで変わるもの |
| --- | --- | --- | --- | --- | --- |
| 1 | 星図の扉 | 扉の4つの記号と、扉の季節（夏／冬） | 夏と冬の星図表（記号→数字） | A（数字4桁） | 記号の並び、季節、表の数字 |
| 2 | 望遠鏡のケーブル | ケーブルを抜く規則（上から順に当てはめる） | 5本のケーブルの色 | B（1本をタップ） | 5本の色 |
| 3 | 止まった時計 | アナログ時計の針 | 時計のずれと、屋根を開ける時刻のメモ | B（時と分） | 針の時刻、ずれ、何時間後か |
| 4 | 暗号の観測ノート | 壁に刻まれた座標4つ | 5×5のかな表 | A（ひらがな） | 単語、表の並び |
| 5 | ドームを開く | 3桁のダイヤルと自分の手帳 | 番号の作り方のページと自分の手帳 | A（数字3桁） | 1〜3の答えから決まる |

- 各端末には**手帳**があり、その端末で入れた答えだけが残る。最終ステージでは、2人の手帳を突き合わせないと番号が作れない
- 間違えても失敗にはならない。間違えた回数は結果画面に出す

### ヒント

- 各ステージ・各役に「ヒント1」「ヒント2」「答え」の3段がある
- 無料シナリオ：ヒント1は無料。ヒント2と答えは、リワード広告を見ると開く（広告は未実装。`AdService` は今は何もせず開く）
- 有料シナリオ：すべて無料で開く

## 4. 収益化（企画書の線引きB案）

- 無料：シナリオ1（2人用）
- 有料：シナリオパック ¥600（非消耗型）。追加シナリオと3〜4人用を含む
- **部屋の持ち主（親）だけが買っていればよい。** 相棒は無料のままで遊べる。有料シナリオの部屋番号は購入済みの端末でしか作れない
  - App Store 3.1.1との整合は要確認。審査メモで「有料部分の解放はIAPのみ。参加者は親の購入した体験に参加しているだけ」と説明する
- 広告：非パーソナライズのみ。全画面広告はシナリオのクリア画面の後だけ。プレイ中と謎の途中には出さない

## 5. 画面

```
タイトル ─┬─ 部屋をつくる → シナリオを選ぶ → 部屋番号と役 → プレイ
          ├─ 部屋にはいる → 部屋番号を入れる → 役の確認 → プレイ
          ├─ 1台で遊ぶ   → シナリオを選ぶ → プレイ（役切り替え）
          ├─ つづきから（遊びかけの部屋があるとき）
          └─ 遊びかた

プレイ ─┬─ ステージの導入文
        ├─ 自分の手がかり（パネル）
        ├─ 答えの入力（自分が入れる番のとき） / 合言葉の入力（相棒の番のとき）
        ├─ 手帳
        └─ ヒント
クリア → エンディング → 結果（時間・ヒント数・間違い数）
```

## 6. コードの構成

| 場所 | 中身 |
| --- | --- |
| `lib/core/rng.dart` | 決定的な乱数 |
| `lib/core/room_code.dart` | 部屋番号の作成と読み取り、検査数字 |
| `lib/core/kana.dart` | 入力のゆれ（カタカナ・全角数字・空白）の吸収 |
| `lib/core/passphrase.dart` | 合言葉 |
| `lib/scenario/model.dart` | シナリオ・ステージ・パネル・入力の型 |
| `lib/scenario/observatory.dart` | シナリオ1の中身 |
| `lib/game/session.dart` | 遊んでいる部屋の状態（進行・手帳・ヒント・時間）と保存 |
| `lib/game/services.dart` | 購入と広告の窓口（今は仮実装） |
| `lib/ui/` | 画面とパネルの部品 |
