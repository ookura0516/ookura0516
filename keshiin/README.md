# ケシイン

今日の1枚が、切手と消印になる。1日1枚の写真を切手に加工し、月ごとのシートに集める記録アプリです。

- 設計：ブランチ `claude/dazzling-planck-qofymj` の「アプリ4案_設計書_第2弾.md」の「案2 ケシイン」と「共通の技術方針」
- 構成とパッケージの選び方は `hisokagi/` に合わせています（provider、shared_preferences、in_app_purchase、flutter_lints）
- アプリ内とストアの説明に「切手風のデザインで、郵便には使えません」と書きます
- ストアに出すまでの人の作業：[docs/STORE_SETUP.md](docs/STORE_SETUP.md)
- ストア素材と掲載文：[store/README.md](store/README.md)、[store/listing_ja.md](store/listing_ja.md)
- プライバシーポリシー：[docs/PRIVACY.md](docs/PRIVACY.md)（アプリ内にも同じ文章）

> **法規制の確認は、まだ人がしていません。** 郵便切手類模造等取締法と郵便法の条文、既存の「切手風フレーム」アプリの表記の確認（設計書「作る前の検証」）は未実施です。下の「法規制への配慮」はコードで入れた予防策で、法的な確認の代わりにはなりません。公開の前に必ず人が確認してください。

## 動かし方

Flutter 3.47（Dart 3.13）で確認しました。

```bash
cd keshiin
```

```bash
flutter pub get
```

```bash
flutter test
```

```bash
flutter analyze
```

```bash
flutter run
```

DB の定義（`lib/data/db.dart`）を変えたときは、生成コードを作り直します。

```bash
dart run build_runner build
```

iOS のホーム画面ウィジェットは、Xcode でターゲットを足す作業が要ります（[ios/KeshiinWidget/README.md](ios/KeshiinWidget/README.md)）。

## できたこと・まだのこと

| 項目 | 状態 | 補足 |
| --- | --- | --- |
| 今月のシート | できた | 5列×6行。今日の空欄は点滅する点線。31日目と同じ日の2枚目以降は欄外。前の月に戻れる |
| 切手を作る | できた | 写真を選ぶ→トリミング（正方形・縦長、指で移動・拡大）→フレーム→消印→保存。写真を選んだらそのまま保存できる（3タップ） |
| アルバム | できた | 月のシートの一覧、旅の小型シート（記念）、年間ポスター（記念） |
| 切手の詳細 | できた | 拡大、消印の編集（日付・場所・一言・押し直し）、共有、削除 |
| 設定 | できた | シート名（禁止語の判定つき）、消印の書体、リマインダー、ZIP の書き出し、写真の容量、購入、注意書き、データの出典 |
| 目打ちの描画 | できた | CustomPainter。辺の長さから穴の数を先に決めて等分するので、角で間隔がそろう。`Path.combine` で穴をくり抜き、薄い影で紙の厚みを出す。三角・菱形も同じ仕組み |
| 消印 | できた | 二重の円、場所（上の円弧）と一言（下の円弧）を1字ずつ回して配置、内側に日付、右に波線。かすれは点と薄い抜けで表現。位置・角度・かすれはシードだけで決まり、シードを DB に保存 |
| 日付と場所 | できた | EXIF の撮影日と GPS を読む。国内は内蔵の1,894件（政令市の区を含む）から最寄りの市区町村を通信なしで引く。40km 以内に無ければ海外とみなし、OS の逆ジオコーディングを使う（通信できないときは空欄にして、場所の履歴から選んでもらう） |
| 過去の日に貼る | できた | 撮影日のマスに自動で振り分け。撮影日が無ければタップしたマスの日。「まとめて貼る」で複数枚を一度に振り分け、すでに貼ってある日は飛ばす（失敗にしない） |
| 共有画像 | できた | 切手を斜めに置いた 1080×1350（紙色・黒の2種）、背景が透明な PNG、月のシート 1080×1350、旅の小型シート、年間ポスター。画像の右下に小さくアプリ名、ストアリンクは入れない |
| データ | できた | drift で stamp・sheet・place_history。元の写真は長辺2400px に縮小してアプリ内にコピー、表示用に長辺600px の縮小版も作る。ZIP（JSON＋元画像）を年ごとに書き出し |
| ウィジェット（Android） | コードはできた・未ビルド | 今月の埋まり「12／30」、5×6の縮小表示、今日の空欄。今日の分と明日の分を書いておき、0時に端末の日付で切り替える。この環境に Android SDK がなく、ビルドと実機での確認はまだ |
| ウィジェット（iOS） | コードはできた・未組み込み | WidgetKit（小・中・ロック画面）の Swift を `ios/KeshiinWidget/` に置いた。Xcode のターゲット追加と App Group の設定はまだ |

| リマインダー | できた・実機未確認 | 1日1回・初期オフ。文面は「今日の切手を貼る？」だけ。設定でオンにしたときだけ通知の許可を求め、時刻（初期は20:00）を選べる。その日の切手を貼ってあれば知らせない。通知をタップすると写真の選択を開く。flutter_local_notifications を使い、Android の正確な時刻の権限は求めない（数分ずれることがある） |

## 法規制への配慮

| やったこと | 場所 |
| --- | --- |
| 額面・通貨記号を描かない。通し番号は「No.12」の形にして、数字だけにはしない | `lib/render/stamp_painter.dart` |
| 「NIPPON」「日本郵便」「郵便」などの文字を、切手・消印・シート・共有画像に描かない | 描画コードに文字は無く、入る文字はユーザーの入力と市区町村名だけ |
| シート名・旅のシート名・消印の場所・一言で、禁止語（郵便、ゆうびん、郵政、〒、NIPPON、ニッポン、JAPAN POST、POSTAGE など）と通貨記号（¥、$、€ など、数字＋円）を弾く。全角・半角・空白区切り・半角カナの書き方も捕まえる | `lib/core/banned_words.dart` |
| 消印の場所に「○○郵便局」「○○局」の形を使わない。海外の地名（OS の答え）も同じ判定を通す | `checkPostmarkPlace` |
| 内蔵の市区町村名・フレーム名・書体名に禁止語が無いことをテストで確かめる | `test/banned_words_test.dart` |
| アプリ内に「切手風のデザインで、郵便には使えません」を出す（初回の案内、シート、切手の詳細、月のシート、設定） | `lib/ui/theme.dart` の `kNotPostageNotice` |
| フレームはすべて自作の幾何模様（白縁・生成り・墨縁・大型・三角・菱形・波・粒・角飾り・夜色・若草）。実在の記念切手をまねたものは作らない | `lib/core/frames.dart` |

## 設計書と違うところ

| 設計書 | このコード | 理由 |
| --- | --- | --- |
| 写真の撮影日と GPS は photo_manager で読む | image_picker（iOS は PHPicker、Android は Photo Picker）で選び、EXIF を exif パッケージで読む | 今回の指示「権限の要らないピッカーを基本にし、写真ライブラリ全体へのアクセスは求めない」に合わせた。photo_manager は写真ライブラリの権限が要る。代わりに、Android の Photo Picker は位置情報を消して渡すことがあり、そのときは場所が空欄になる（履歴から選ぶ） |
| 共有画像は RepaintBoundary で PNG 化 | `PictureRecorder` で直接 1080×1350 に描く | 画面の大きさや画素密度によらず同じ画像になり、画面に出していないもの（年間ポスターなど）も作れる。画面の表示も共有画像も同じ描画関数を使う |
| 写真はシート用 600px と共有用 1600px の2サイズを保存し、元画像はそのまま残す | 元画像を長辺2400px に縮小して保存、表示用に600px の縮小版 | 今回の指示「長辺2400px に縮小してアプリ内にコピー」と、設計書「リスクと対策」の容量対策に合わせた。共有画像は2400px から作る |
| stamp の列 | `shape`（square / portrait）を追加 | トリミングの縦横をあとから描き直すため |
| 「記念」で解放する機能（設計書の一覧に「バックアップ」） | ZIP の書き出しは無料 | 今回の指示で ZIP の書き出しが「データ」の項目にあり、記録アプリでデータを持ち出せないのは困るため |
| 消印の書体 | 端末の書体（ゴシック・明朝・太ゴシック）を使う。フォントファイルは同梱しない | アプリの容量を増やさないため。端末によって見た目が少し変わる |
| 市区町村の代表座標は国土地理院のオープンデータ | Geolonia 住所データ（CC BY 4.0、国土交通省「位置参照情報」ほかをもとに加工）の町字の代表点から、各市区町村で「町字の重心に最も近い町字の点」を代表点にした（1,894件） | この環境から取得でき、ライセンスが明確だったため。代表点は役所の位置ではない。出典は設定画面に表示している |
| リマインダーは1日1回 | 毎日くり返す通知ではなく、この先14日ぶんを1日1件ずつ予約し、アプリを開いたときと切手を貼った・消したときに予約し直す | くり返しの通知では、貼り終えた日にも通知が来てしまう。14日以上アプリを開かなければ通知は止まる（iOS の予約は64件まで） |
| ウィジェットの中サイズはシートの縮小画像 | 5×6 の記号（■□◇）で表示 | 画像の受け渡し（App Group のファイル）を省き、Android の RemoteViews でも同じ表示にするため |

## ファイル

| 場所 | 中身 |
| --- | --- |
| `lib/core/` | 描画や画面に依存しない処理（目打ち、禁止語、日付とマス、市区町村、消印のずれ、EXIF、フレームの定義） |
| `lib/render/` | 切手・消印・シート・共有画像の描画 |

| `lib/platform/` | 写真の選択、逆ジオコーディング、共有、ウィジェット、評価依頼（テストでは偽物に差し替え） |
| `lib/monetize/` | 購入（仮の実装と in_app_purchase の実装） |
| `lib/ui/` | 画面 |
| `assets/data/municipalities.csv` | 市区町村の代表座標（code, pref, city, lat, lng） |
| `android/app/src/main/kotlin/.../KeshiinWidgetProvider.kt` | Android のウィジェット |
| `ios/KeshiinWidget/` | iOS のウィジェット（Xcode への組み込みはまだ） |
| `store/` | ストア素材、掲載文、素材とスクリーンショットを作るスクリプト（`store/src/`） |
| `docs/` | ストアに出すまでの手順、プライバシーポリシー |
