# ひそかぎ

スマホを持ち寄って、声で解く。ふたりの協力謎解き。

2人がそれぞれ自分のスマホを持ち、画面に出る「自分だけの手がかり」を伝え合って解きます。通信もサーバーも使いません。部屋番号（6桁）と合言葉で2台の進行をそろえます。

- 設計：[docs/DESIGN.md](docs/DESIGN.md)
- 課金と広告の設定手順：[docs/STORE_SETUP.md](docs/STORE_SETUP.md)
- 収録シナリオ：「閉館後の天文台」（無料・2人用・約30分・5ステージ）
- 1台を交代で使う「1台で遊ぶ」モードもあります

## 動かす

```bash
flutter pub get
```

```bash

```

