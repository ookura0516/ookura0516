# タンザク

詠んだ句が、そのまま短冊になる。俳句の句帳。

- 3行で詠むと、音数の目安と季語（季節・分類）がその場で出る。季重なりも知らせる
- 縦書きの短冊・色紙の画像にして、写真に保存したり X などに共有したりできる
- 毎日1つの兼題（季語）。二十四節気で「今の季節」が切り替わる
- サーバーもアカウントも使わない。句は端末の中（SQLite）だけ。広告なし

設計書：リポジトリの `claude/dazzling-planck-qofymj` ブランチの「アプリ4案_設計書_第2弾.md」の「案1 タンザク」と「共通の技術方針」。

## 動かし方

Flutter 3.47.9（Dart 3.13）で確かめた。ひそかぎと同じ版。

```bash
cd tanzaku
```

```bash
flutter pub get
```

```bash
flutter test
```

```bash
flutter run
```

データベースの型（`lib/data/database.g.dart`）は生成済みでコミットしてある。`lib/data/database.dart` を変えたら作り直す。

```bash
dart run build_runner build
```

歳時記を足したら JSON を作り直す（手順は [assets/data/README.md](assets/data/README.md)）。

```bash
python3 tool/build_kigo.py
```

短冊の見本画像を書き出して目で確かめる（フォントを読み込んで本番と同じ絵を描く）。

```bash
flutter test tool/render_samples_test.dart --dart-define=OUT=/tmp/tanzaku
```

## 設計書と違うところ（理由）

| 設計書 | このアプリ | 理由 |
| --- | --- | --- |
| 季語約600語 | 150語 | 依頼が「まず150語、データの形は600語まで、残りは人が足す」だったため |
| 追加書体の候補：衡山毛筆・しっぽり明朝 | しっぽり明朝と Yuji Syuku（筆の書体） | 衡山毛筆はアプリ同梱の可否を文面で確かめられなかった。Yuji Syuku は Google Fonts 配布の OFL 1.1 で、組み込み・商用・同梱を文面で確かめられた |
| Noto Serif JP | 可変フォントから太さ400の静的フォントを作って同梱 | 可変フォントの既定の太さが200（細すぎる）ため。OFL は改変を許し、予約フォント名もない |
| 書き出しは JSON＋画像の ZIP、バックアップ書き出しは有料 | JSON だけ、無料 | 依頼の範囲が「JSON の書き出しと読み込み」で、有料の項目にバックアップが入っていなかった。端末だけにデータがあるアプリで、退避の手段を有料にすると機種変更で句を失うおそれがある |
| 共有画像は RepaintBoundary で PNG 化 | プレビューと同じ `CustomPainter` を `PictureRecorder` で直接 PNG にする | 画面の大きさや端末の倍率によらず、ちょうど 1080 px の画像になる。見た目はプレビューと同じ |
| 連続日数は「途切れても1回だけ復活」 | 抜けた日が昨日1日だけなら「昨日の分を詠む」で復活 | 「1回だけ」を、さかのぼれるのは1日分だけと読んだ |
| `kigo` テーブルの列 | `period`（「初冬」など）と `examples`（例句）を足した | 歳時記画面で時期の名前と例句を出すため |
| 通知は兼題の時刻に1日1回 | 14日分を1件ずつ予約し、起動のたびに入れ直す | 季語が日ごとに変わるので、毎日くり返す1件の通知では中身を変えられない |
| 共通基盤 ookura_design ほか | 使っていない | ひそかぎと同じく非公開パッケージで、この環境では使えない。配色・文字サイズはアプリ内で同じ考え方で作った |

## フォルダ

| 場所 | 中身 |
| --- | --- |
| `lib/core` | 縦書き・音数・季語・二十四節気・兼題・連続日数など、画面によらない処理 |
| `lib/data` | drift のテーブルと、句帳の読み書き・書き出し |
| `lib/render` | 短冊・色紙・十句ポスターの描画、PNG と PDF |
| `lib/services` | 設定、購入、共有・通知・ウィジェット・評価依頼（差し替えられる形） |
| `lib/ui` | 画面 |
| `assets` | 歳時記の JSON、フォント、フォントのライセンス文 |
| `tool` | 歳時記の JSON を作るスクリプト、見本画像の書き出し |
