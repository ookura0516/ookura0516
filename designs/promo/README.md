# 宣伝動画（モンキリ・メイロ便・コゼニ）

[3案の設計書](../アプリ3案_設計書_モンキリ・メイロ便・コゼニ.md) をもとにした宣伝動画です。アプリはまだ無いので、設計書の画面を再現したイメージ映像です。終わりの画面に「※画面は開発中のイメージです」と入れています。

## できたもの

`out/` に6本あります。どれも 30fps、H.264、AAC（44.1kHz）です。

| ファイル | 形 | 長さ | 中身 |
| --- | --- | --- | --- |
| `kozeni_vertical.mp4` | 縦 1080×1920 | 20秒 | 864円の払い方（千円札だけ→小銭15枚、1,064円→5枚）、レシート、挑戦状 |
| `kozeni_horizontal.mp4` | 横 1920×1080 | 30秒 | 同じ流れ。右側に見出しと説明 |
| `meirobin_vertical.mp4` | 縦 1080×1920 | 20秒 | 届いた手紙を開く、迷路を解く（行き止まりの文字が消える）、読む、書いて送る |
| `meirobin_horizontal.mp4` | 横 1920×1080 | 29秒 | 同じ流れ |
| `monkiri_vertical.mp4` | 縦 1080×1920 | 20秒 | 雪折りに折る、指で切る、ひらく、図鑑、リンクで届いた梅をひらく |
| `monkiri_horizontal.mp4` | 横 1920×1080 | 30秒 | 同じ流れ。「1 折る・2 切る・3 ひらく」の番号つき |

- 縦は TikTok・Instagram のリール・YouTube ショート・X 向け、横は紹介ページの上部と YouTube 向けです
- 字幕は映像に焼き込んであるので、音を消して見ても分かります
- 画面の中身は作り物ではなく、設計書の仕組みを実際に動かして描いています。コゼニの払い方とお釣りは計算どおり、メイロ便の迷路は設計書の作り方（入口から掘り進めて戻る）で作った迷路で、文字は正しい道の上にあります。モンキリの模様は、扇の切り取りを回転と鏡映で写して作っています

## 使うときの注意

- **App Store のプレビュー動画には使えません。** App Store のプレビューは、アプリの実際の画面を録画したものである必要があります。アプリができたら、実機の録画で作り直してください。Google Play の動画（YouTube のリンク）、SNS、紹介ページには使えます
- 終わりの画面の「App Store・Google Play で配信」は文字だけで、公式のバッジは使っていません。バッジを使う場合は、各社の決まり（Apple の App Store マーケティングガイドライン、Google Play のバッジのガイドライン）に沿って入れてください
- 公開する URL（`xxx.pages.dev`）はまだ決まっていないので入れていません。決まったら、各アプリの `endCard` に足して書き出し直します
- 硬貨とお札は、設計書の方針どおり「色の付いた丸と長方形に額面の数字だけ」で、本物の図柄は描いていません。通貨の描き方の法令の確認は、設計書と同じく人が行う前提です

## 書き出し方

要るもの：Node.js、Playwright と Chromium、ffmpeg、Python 3（numpy・scipy）。

```bash
cd designs/promo
```

```bash
npm install
```

```bash
node render.mjs
```

1本だけ書き出すときは、アプリ名と形（`v` は縦、`h` は横）を付けます。

```bash
node render.mjs kozeni v
```

決まった時刻の静止画だけを書き出して確かめることもできます。

```bash
node render.mjs monkiri h --still 1.5,6,12 --out /tmp/stills
```

この環境では、1本あたり40〜70秒で書き出せました。

## ファイル

| 場所 | 中身 |
| --- | --- |
| `index.html` | 描画するページ。`?app=kozeni&fmt=v` のように開く |
| `src/engine.js` | 共通の部品（文字、図形、スマホの枠、押した指のしるし、ボタン、乱数） |
| `src/main.js` | 場面の並び、字幕、終わりの画面、効果音のきっかけをまとめて1コマを描く |
| `src/kozeni.js` | コゼニの場面（払い方と判定、レシート、挑戦状） |
| `src/meirobin.js` | メイロ便の場面（迷路の生成、文字の配置、封筒、書く画面） |
| `src/monkiri.js` | モンキリの場面（6種類の紋の切り取り、折る・ひらく動き、図鑑） |
| `render.mjs` | 1コマずつ描いて ffmpeg に渡し、音を重ねる |
| `audio.py` | 曲と効果音の合成。コゼニはマリンバ風（F長調）、メイロ便はオルゴール風（C長調）、モンキリは琴風（D の陽音階） |

## 直すとき

- 場面の長さ：各アプリの `scenes` の `dur`（`v` が縦、`h` が横の秒数）
- 字幕：各場面の `cap`。縦は `text`、横は `h`（見出し）と `s`（説明）。`a`・`b` は場面の中で出す範囲（0〜1）
- 効果音：各場面の `cues` が時刻と種類を返す。音そのものは `audio.py` の `SFX`
- アプリの実際の画面ができたら、`screen` の関数を録画に差し替えるより、実機で録画し直すほうが確実です
